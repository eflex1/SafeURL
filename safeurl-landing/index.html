Real-Time AI-Powered Phishing URL Detection Using Browser Extensions and Machine Learning

SafeURL is a browser-integrated threat inspection architecture. It intercepts outbound web navigation, performs real-time feature vector extraction, and calculates predictive phishing probabilities using an ensemble Random Forest model.

Core Subsystems

Architectural Components

Lexical Feature Extractor

Calculates domain entropy, structural dot/hyphen distributions, numerical density, and sensitive administrative/financial path tokens without deep packet inspection.

Random Forest Classifier

Evaluates multi-dimensional vector inputs across 50 estimators capped at maximum tree depth to optimize inference latency under 80 milliseconds.

Asynchronous Telemetry

Logs incoming scan events, prediction scores, and target domains to a managed MySQL cloud cluster using connection pooling and SSL encryption.

Setup Guide

Manual Extension Installation

01
Download Archive: Click the download button above or clone the repository from GitHub.
02
Extract Files: Unzip the downloaded file to access the safeurl-extension folder.
03
Open Chrome Extensions: Navigate to chrome://extensions in your Google Chrome address bar.
04
Enable Developer Mode: Toggle the Developer mode switch in the upper-right corner.
05
Load Extension: Click Load unpacked and select the extracted safeurl-extension directory.
